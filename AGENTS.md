# Relay project instructions

Relay is a standalone public-source candidate. Never copy private ROVER code, migrations, assets, credentials, or history into it. Do not add a private package dependency.

Use the actual Meterless H-MEM engine and preserve upstream attribution. Keep models and external data behind adapters. Sample mode must not call external services and must visibly identify sample output. Do not claim a live sponsor integration from controlled tests or fixture responses.

Validate every boundary. Models cannot execute SQL or create dispatch tasks. Preserve plan versions, owner checks, expiry, source revalidation, atomic task reservation, idempotency, and outbox deduplication. Use structured decisions rather than private model reasoning transcripts.

Do not call observed stock a reservation or simulated operations a real booking. Never silently relax a user's constraints. Record pre-event work accurately.

Run the behavior tests and production build for affected changes. Run only one application process per H-MEM data directory. New deployment and publication are separate actions; do not infer that a request to edit code authorizes them.
